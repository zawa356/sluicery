### 修正
- Phase 7レビュー指摘に対応し、publish先の同名ファイルが期待サイズと異なる場合の上書き拒否と、index後のStaging削除がOSErrorになってもDB確定を覆さない経路へ回帰テストを追加
- Phase 7レビューで検出したArtifact `format_id`の誤記録を修正。ffprobeのstream indexではなく、yt-dlpのafter_move構造化出力から実際のformat IDをdownload → verify → indexへ受け渡す
- Phase 7レビューで検出したTask / Target終端同期を修正。Taskの再試行上限・直接unavailable・stale上限をTarget unavailableへ、実行中／待機中cancelをTarget failedへ条件付き単一UPDATEで反映し、handler例外時もTargetを取り残さない
- Phase 7の実機検証で検出したTaskキャンセル伝播を修正。待機中Taskの直接キャンセルと、実行中Taskのキャンセル確定時に、依存する後続チェーンも`cancelled`へ遷移させる
- Phase 7のdownload中断試験に先立ち、部分ファイル再開をyt-dlpの暗黙既定に依存せず、アプリ予約引数`--continue`として常時有効化
- Phase 7のSMB復旧試験で検出したpublish再開処理を修正。Storage障害で`blocked`になったTargetを、再試行時に比較更新で`processing`へ戻してからpublishを再開する
- Phase 6独立レビューで検出したTask所有権競合を修正。失敗再試行を所有権条件付き単一UPDATEへ変更し、stale回収・再claim後の旧workerによる状態上書きを拒否する。cancel / retryとclaimの競合も状態条件付きUPDATEで直列化し、最後のheartbeat後のcancel要求はfailed / blockedより優先してcancelledへ確定する
- composeの通常buildがDockerfile最終段のtest stageを選び開発依存を本番イメージへ含めていたため、全サービスのbuild targetをruntimeへ固定
- worker IDへ起動ごとのnonceを追加。同一コンテナの再起動でhostnameとPIDが同じでも、異常終了前のTask所有者と衝突しないよう修正
- `AUTO_MIGRATE=false` でDBがhead未満のdegraded起動時はstale回収器を開始せず、欠落カラムへのアクセスで回収スレッドが終了しないよう修正
- 独立レビューで検出した publish 安全性を修正。local は Staging 元を成功まで保持して hardlink/copy で一時名を作り、原子的 no-replace rename で競合上書きを拒否する。remote は `--ignore-existing` と一時名消滅確認で競合を検出する
