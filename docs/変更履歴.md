### 追加
- 12イベントを`config/hooks.yaml`で購読し、組み込み`event_log`へ単一workerのbounded非同期queueで順序付き記録するHook機構を追加。イベント別payload allowlist、URL / 秘密key除外、不正設定の空購読fallback、失敗隔離、producer停止後flushを実装した。検証環境のapp / network worker / compute workerで全12購読を確認した
- Playlist、Profile、割当、Storageのportableな非秘密設定、グローバル設定を単一YAMLへexportし、署名付き差分preview後にimportする画面を追加。衝突時のskip / overwrite / create、厳密schema、資格情報・Cookieの常時消去、remote Storageとretentionの再確認を実装した
- Phase 17の実環境読み取り検証で10,675 bytes、Storage 3、Profile 7、Playlist 8、割当19、設定1をexportし、秘密値一致0、禁止フィールド一致0、DB不変を確認した。3種類のimport previewもDB不変で、実ファイル操作は行っていない
- Playlist単位のretentionを追加。既定無効、最新N件 / M日超の保持ポリシー、有効化時と実行時の署名付きdry-run確認、20件上限、過半数guard、300秒TTL、Playlist排他、単一path削除、fsync済み監査logを実装した。削除成功後はArtifactを削除しTargetを`ignored`にする
- Phase 16の検証環境確認は読み取り専用で実施し、retention有効Playlist 0、候補0、Artifact 599件不変を確認した。実メディアは削除せず、合成一時ファイルだけで削除経路を検証した。全448テスト、Ruff、mypy 85 source filesが成功した
- yt-dlpの週次自動更新、実ダウンロード・Deno検出・challenge警告・default extras・メタデータ/サムネイル埋込みを確認する強化スモークテスト、健全な直前版だけへの自動ロールバックを追加。新旧両方が失敗した場合は新版を維持し、`run_failed` Hookへ記録する
- yt-dlp更新管理画面とCLIの`ytdlp update` / `rollback`を追加。現在版、最終スモーク結果、更新履歴を表示し、手動ロールバックも候補の実ダウンロード検査後だけ切り替える
- Profile編集画面から任意URLの利用可能format、現在のselectorによる選択、推定サイズを確認できるフォーマット検査を追加。Phase 4のオプション合成とdiscover timeoutを再利用し、全Profile共通の既定10秒レート制限、入力URLのログマスク、Storage非保存を実装した
- Phase 13のlocal / SMB隔離実機検証を実施。移動・改名relink、missing・復帰、IDなし孤立、手動リンク・取消、複数候補の非選択を確認した。実DBのマイグレーション往復、日次job、SQLite整合性も確認し、合成データを対象限定で片付けた。レビュー対応後の全419テスト、Ruff、mypyが成功した
- Storage / Playlistで絞り込める`sluicery integrity check`と、`app`専用スケジューラの日次integrity jobを追加。永続jobの引数は空とし、秘密値やStorageパスを保存しない
- delisted Itemと関連Artifactパスを、Playlist・期間で絞り込める読み取り専用の差分レポートを追加。retentionと分離し、削除操作を持たない
- missing TargetとStorage内のArtifact未追跡ファイルを並べる整合性レポートを追加。手動リンクと取消はDBパスと状態だけを更新し、実ファイルを削除・移動しない
- Playlist単位のmissing方針（放置・再取得・無視）を追加。既定は放置で、自動再取得は明示設定時だけ有効になる。Web UIとCLIから選択できる
- Storage単位で1回だけ再走査する読み取り専用の整合性チェックを追加。末尾`[source_id]`が一意ならDBパスだけをrelinkし、複数候補・走査エラー・タイムアウトでは自動選択やmissing誤判定を行わない
- Phase 13準備としてCookieなしの限定取得試験を1件実施。Deno検出済みでもHTTP 403となり生成物0件だったため、Cookieを必要なPlaylistだけで使う運用判断をD-053として記録した
- Phase 12の実機検証を実施。app専用jobstore、独立cronと60秒以内の設定反映、`TZ`表示、対称jitter、時間帯外・手動競合の`skipped`記録、paused / 削除時のjob除去、停止中3回分を復帰直後の1回へ畳み込むmisfireを確認した。合成レコードと一時設定は対象指定で削除し、既定状態へ復元した
- `RunStatus.skipped`を追加するAlembicマイグレーションを追加。downgrade時は既存の`skipped`を`cancelled`へ写像してから旧CHECK制約へ戻す
- 起動時と60秒ごとにPlaylist設定と永続ジョブを整合し、削除・無効・一時停止されたPlaylistのジョブを除去する。各ジョブは24時間のmisfire猶予、`coalesce=true`、`max_instances=1`で直近1回だけ実行する。起動時だけ未完了Taskのない古いrunning Runを、stale回収器は試行上限に達したdiscover Runを終端する
- `schedule.download_window`の`HH:MM-HH:MM`検証とdownload時間帯制限を追加。日中・日跨ぎ・同時刻（終日）を扱い、範囲外の自動downloadはTaskを投入せず理由付き`skipped` Runへ記録する。discoverと手動downloadには適用しない
- appサービス専用のAPSchedulerと既存SQLite上のSQLAlchemyJobStoreを追加。Playlistごとのdiscover / download独立cron、グローバル既定、`TZ`解釈、±ジッター、paused除外、次回予定表示を実装した。同一Playlistの手動・自動同期はDB上で直列化し、自動実行の競合は`skipped` Runとして記録する
- Run詳細からTask単位・Run単位のキャンセルを確認ダイアログ付きで要求できるようにした。待機中は即時cancelled、実行中はheartbeat経由の協調停止とし、Run cancelled確定後は遅れて完了したhandlerによる成功への上書きを拒否する
- workerがyt-dlp / ffprobe / rcloneの一次マスク済みログをRun単位へ集約し、Run詳細から末尾500行とマスク済み全文を閲覧可能にした。表示時にも認証形式を二次マスクし、DBの`run.log_path`を起点に解決後のパスが`DATA_DIR`内の通常ファイルである場合だけ読む
- Run詳細に`payload_json.progress`を読むHTMX進捗表示を追加。実行中Taskの種別・対象・進捗率・速度・ETAを3秒間隔で更新し、実行中Taskが無くなった部分レスポンスからポーリング属性を除去して停止する
- Run履歴の一覧・詳細を追加。trigger、kind、状態、統計、所要時間、関連Taskの状態内訳を表示し、Run / Taskの状態フィルタと50件ページネーションを提供する。download Runは「投入結果」と取得Taskの成否を明確に区別する
- 運用設定のWeb画面を追加。全コード既定とDB上書きを由来・型付きで表示し、厳密な型・範囲・相互しきい値検証、個別上書き・既定値復帰、パスワード変更導線を提供する。`_internal.*`は表示・更新対象外とする
- StorageのWeb CRUDと4段階接続テストを追加。localの`/mnt/media`境界とremote SMB設定を検証し、空き容量・参照Playlist・最終結果を表示する。クレデンシャルは暗号化してwrite-onlyで扱い、レコード削除ではメディアファイルを操作しない
- ProfileのWeb CRUDを追加。継承 / 有効 / 無効の三状態を6項目で明示し、参照Playlist、由来層付きのマスク済みコマンドラインプレビュー、Phase 14予定のフォーマット検査表示を提供する
- PlaylistのWeb CRUD、enabled / paused、manual discover / download、Cookie設定導線、Profile割当、50件ページネーション・状態フィルタ・検索付きItem / Target一覧、個別retry / ignoreを追加
- Playlist削除時にItem保持（無効化・一時停止）と関連DBレコード削除を明示選択させ、どちらもメディアファイルを削除しないことを画面に表示する
- Webダッシュボードを追加。直近Run、yt-dlp状態・バージョン・最終導入、Staging使用率、Storage最終到達性、failed / missing / delisted件数を表示し、次回予定はPart Dまで未実装と明示する
- Playlist単位のyt-dlp Cookie対応を追加。Netscape形式を確認後にEncryptedJSONへwrite-only保存し、有効時だけtmpfsへ600で展開する。discover / downloadの終了・例外時に必ず削除し、yt-dlpの書き戻しはDBへ反映しない（D-047）
- `--cookies` / `--cookies-from-browser`の自由入力を拒否し、一時パスとCookie値をRunnerのマスク対象へ追加。UIで停止リスクの明示確認を要求する
