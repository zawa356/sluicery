### 修正
- yt-dlp venv のインストール時、pip の console_scripts（`bin/yt-dlp` 等）がシェバンにインストール時の絶対パス（`versions/.tmp-<uuid>/`）を焼き込むため、`versions/<version>/` へリネームした直後は実行不能（`broken`）になっていた問題を修正。リネーム後にシェバンを新パスへ書き換える（実機検証 §11.2 #4 で発見）
- `ytdlp install --force` が、解決したバージョン名のディレクトリが既に存在する場合に新しい venv を無条件で破棄していたため、`broken` な既存を `--force` で上書き・復旧できなかった問題を修正（実機検証 §11.2 #18 で発見）
- `ytdlp fetch` で `--print` が既定で暗黙付与する `--quiet` により `--progress-template` の進捗出力まで抑制され、進捗が一切表示されない問題を修正。`--progress` を明示的に追加した（実機検証 §11.2 #9 で発見）
- SQLite で `DateTime(timezone=True)` が tzinfo を保持しない問題を `UTCDateTime` 型で修正（D-007）
- `.env.example` の `SECRET_KEY` 生成例が Fernet の期待する形式でなかった問題を修正
- `.gitignore` のアンカー未指定（`data/` 等が任意階層にマッチしていた）を修正
- AISTATE.md の要件定義からの用語ドリフトを是正
- `MEDIA_ROOT`（ホスト側 bind mount パス）の存在・書き込み検証が、コンテナ内では存在しないホスト側パス文字列をそのままチェックしており、既定値以外の `MEDIA_ROOT` を設定すると起動できない問題を修正（`docker compose up` の実地検証で発覚。D-010）
- `.gitignore` に `backups/` が無く、`make backup` が書き出すクレデンシャル入りアーカイブが除外されていなかった問題を修正（`*:Zone.Identifier` は既に対応済み）
- `make lint` が `requirements-dev.in`（バージョン非固定）から直接インストールしており、実行時期によって ruff/mypy のバージョンが変わり同じコードで結果が変わっていた問題を修正。`make test` と同じ `sluicery:local-test` イメージを使う形に統一し、`make lock` のベースイメージも Dockerfile と同じ digest を参照するよう変数化した
- `make purge` が `sluicery:local-test` を削除対象に含めておらず、手動での `docker rmi` が必要だった問題を修正
- README Quick Start の `SECRET_KEY` 生成コマンドが、`python:3.12-slim` に `cryptography` が含まれておらず `ModuleNotFoundError` で失敗する問題を修正（VM実機検証 §5 #2 で発見）
- `MEDIA_ROOT` を事前作成しない場合、Docker がroot所有で自動作成するため `app` が起動時 FATAL で再起動ループに陥る問題を修正。Quick Start に事前作成手順を追加（VM実機検証 §5 #2 で発見）
- `docker compose exec app`（`--user` 無指定）がrootとして実行され、`ytdlp fetch` 等の生成物がroot所有になる問題をドキュメント側で修正。CLI例に `--user "$(id -u):$(id -g)"` を追加（VM実機検証 §5 #9 で発見）
