# 利用上の注意

sluicery は yt-dlp を用いて登録済みプレイリストの内容を取得・保存する自己ホスト型ツールです。
利用前に以下を必ず確認してください。

## 想定利用者・利用範囲

- 単一の技術者が、私的使用の範囲で運用することを前提としています（要件定義 §1.2, §1.3）。
- 外部公開・他人との共有は非対応です。マルチユーザー機能・共有リンク・公開 API は実装されていません。
- 2 件目のユーザー作成は仕様として禁止されています。

## コンテンツの取得について

- DRM（デジタル著作権管理）で保護されたコンテンツの取得は対象外です。sluicery はその回避手段を実装しません。
- 取得するコンテンツの著作権・利用規約の遵守は利用者自身の責任で行ってください。
- Cookie を利用した認証ゲート付きコンテンツの取得は既定で無効です。有効化する場合、アカウントに紐づく大量アクセスは規約違反や凍結のリスクがあることを理解した上で行ってください。

## データの取り扱いについて

- 配信元でコンテンツが削除・非公開化されても、ローカルに保存済みのファイルが削除されることはありません（同期では `delisted` として記録するのみ、要件定義 §1.4 設計原則1）。
- バックアップ（`make backup`）にはクレデンシャル（Storage 認証情報など）を暗号化のまま含める場合があります。取り扱いに注意してください。
- クレデンシャルの暗号化鍵は `.env` の `SECRET_KEY` です。**ローテーションには対応していません。** 紛失または意図しない変更があった場合、保存済みの認証情報は復号できなくなり、各 Storage の認証情報を再入力する必要があります（起動時に鍵の指紋を照合し、前回と異なる場合は警告を表示します）。`SECRET_KEY` はバックアップと同様に厳重に管理してください。

## 免責

本ツールは自己責任での利用を前提としています。取得したコンテンツの利用・保管によって生じたいかなる問題についても、利用者自身が責任を負うものとします。
